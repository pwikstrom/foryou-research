Open source

The Data Hub is free software under the MIT licence, developed in the open at {{ repo_url | replace('https://', '') }}. The whole pipeline is in that repository, so you can read exactly how a donation becomes a research variable, and run your own instance, keeping participant data on infrastructure you control.

  • Run it yourself: the installation guide covers a laptop install for small studies and a Google Cloud Run deployment for larger ones.
  • Bugs and feature requests: open an issue. Please keep participant data out of public issues, and report security problems privately per the security policy.
  • Contributions: pull requests are welcome; see the contributing guide.
  • Citing it: the repository carries a CITATION.cff with the archived DOI, so GitHub's "Cite this repository" button gives you a ready-made reference.

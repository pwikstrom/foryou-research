Versions

The annotation contract is a file that is used to generate both the annotation prompt and the response schema used for the annotations. Upload an edited annotation_contract.toml to change the contract or edit the contract as a form in the app. Every time you change the contract, you generate a new annotation version. The annotation version controls exactly how an annotation is produced: which AI model, prompt, response format and settings are used. Annotations using a certain version are stamped with the version id, to record how the annotation was made. Note that even if a video is re-annotated, past annotations are never deleted. Results from past annotations remain in the dataset and can be used if a study so requires.

We refer to two different version types:

  • Current: The version holding the instructions for the next annotation
  • Preferred: The version used to build annotation datasets for analysis. If a video has annotations made with multiple versions, the annotation made with the preferred version is selected (if available). If the video has not been annotated with the preferred version, the most recent annotation will be used. Changing preferred version requires a refresh of relevant study datasets to be applied.

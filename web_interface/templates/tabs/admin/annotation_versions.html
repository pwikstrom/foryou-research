Versions

An annotation version controls exactly how an annotation is produced: which AI model, prompt, response format and settings are used. Annotations using a certain version are stamped with the version id, to record how the annotation was made. Versions are created ("baked") from an annotation contract on the Playground page — that is where you author, test and graduate contracts. This page is the version history: inspect any version, choose which one analyses read, and restore an earlier version for new annotations. Note that even if a video is re-annotated, past annotations are never deleted — results from past annotations remain in the dataset and can be used if a study so requires.

We refer to two different version types:

  • Current: The version holding the instructions for the next annotation. Change it by graduating a contract in the Playground, or by pressing Make current on an earlier version below to restore it.
  • Preferred: The version used to build annotation datasets for analysis. If a video has annotations made with multiple versions, the annotation made with the preferred version is selected (if available). If the video has not been annotated with the preferred version, the most recent annotation will be used. Changing preferred version requires a refresh of relevant study datasets to be applied.

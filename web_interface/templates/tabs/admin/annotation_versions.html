Annotation Versions

Every annotation is stamped with a content-derived version (model + prompt + response schema + generation parameters). Old versions are never overwritten — the full history is archived and queryable. The active version is what studies read by default; it stays pinned until you promote a new one. Promoting rebuilds the global active dataset; refresh studies afterwards to apply it to per-study datasets.

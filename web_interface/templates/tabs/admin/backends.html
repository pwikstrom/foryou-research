Backends

Machine annotation

The backend that annotates videos. Model and generation parameters (temperature, thinking budget, media resolution, max output tokens) are set in the [machine] section of config/config.toml and require a rebuild/redeploy to change.

Changing the backend (or the configured model/parameters) forks a new annotation version (av_…). Existing annotations stay under their version; see Admin → Annotation Versions.

Embeddings

The model that embeds annotated videos for the Semantic Space map. Chosen independently of the annotation backend — with both set to a local backend, embeddings and the semantic map run with no cloud calls (niche names then come from each niche's top terms instead of Gemini).

Changing the backend re-embeds the corpus under the new model on the next embeddings refresh (existing vectors are kept, so switching back costs nothing). Rebuild the video map afterwards.

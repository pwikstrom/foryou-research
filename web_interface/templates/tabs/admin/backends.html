Backends

Machine annotation

The backend that annotates videos. Model and generation parameters (temperature, thinking budget, media resolution, max output tokens) are set in the [machine] section of config/config.toml and require a rebuild/redeploy to change.

Switching the backend changes how new annotations are made from now on: a new annotation version (av_…) becomes active and future annotations are stamped with it. Existing annotations are untouched, and analyses keep reading the preferred version — nothing needs to be refreshed until you re-annotate videos and promote the new version on the Versions page.

Embeddings

The model that embeds annotated videos for the Semantic Space map. Chosen independently of the annotation backend — with both set to a local backend, embeddings and the semantic map run with no cloud calls (niche names then come from each niche's top terms instead of Gemini).

Changing the backend takes effect on the next embeddings refresh, which re-embeds the corpus under the new model (existing vectors are kept, so switching back costs nothing). To apply it, run Embeddings → Refresh and then Video map → Rebuild under Data Pipeline → Refresh Caches; until then the Semantic Space map keeps showing the previous model and reports itself as stale.

Data Contracts

Besides the annotation contract (authored and activated on the Contracts page), the Hub's variable schema is governed by three further declarative contracts: the scrape contract (the canonical cross-platform scrape schema), the activity contract (the platform-agnostic donation/engagement schema) and the derived contract (columns computed at merge time). This page is a read-only view of those contracts and, for scrape and activity, their version history — every stored row is stamped with the contract version it was produced under.

These contracts are deliberately not editable here: their fields only change together with the scraper / ingester code that emits them, so they are edited in the repository and deployed. A deployed change forks a new version automatically.

Machine annotation

Runtime overrides of the [machine] configuration. Leave a field empty to use the config default (shown as the placeholder). Changes apply from the next annotation run — no restart needed.

Changing the model or any generation parameter forks a new annotation version (av_…). Existing annotations stay under their version; see Admin → Annotation Versions.

Embeddings

The model that embeds annotated videos for the Semantic Space map. Chosen independently of the annotation backend — with both set to a local backend, embeddings and the semantic map run with no cloud calls (niche names then come from each niche's top terms instead of Gemini).

Changing the backend re-embeds the corpus under the new model on the next embeddings refresh (existing vectors are kept, so switching back costs nothing). Rebuild the video map afterwards.

Hashtag stoplist

Hashtags matching this list are dropped when captions are tokenised during scraping and annotation. Edits apply from the next scrape/annotation run; already-stored hashtags are unchanged. Repeated letters match automatically (fyp also catches fyyyyp and fypp); end an entry with * to match any hashtag starting with it (fyp* catches fypage).

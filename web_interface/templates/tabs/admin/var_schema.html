Variable Schema

This table is a read-only view of the variable schema. Each variable's recoding, name, role, scale and source is owned by the declarative contracts (config/*_contract.toml) and the version registries, so those cells can't be edited here. The only editable cells are the four surface checkboxes — Filter, Display, Timeline and Viz: they set the global default set of variables shown on each surface, which every user can then tailor for themselves via the “Customize variables” gear on that tab. Toggling a checkbox saves immediately and never triggers a study rebuild.

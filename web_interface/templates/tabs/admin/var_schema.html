Variable Visibility

This page sets which variables are shown or hidden by default across the app. Tick a checkbox to include a variable on that surface — Filters, Timelines, Explore or Video Analysis; changes save immediately and never trigger a study rebuild. These are only the global defaults: every user can tailor their own set via the “Customize variables” gear on each tab. The remaining columns describe each variable for reference — they are owned by the declarative contracts (config/*_contract.toml) and the version registries, and can only be changed there.

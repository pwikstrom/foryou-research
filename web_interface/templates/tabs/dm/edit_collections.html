Automatic enrichment{{ card_info( "A donated collection starts as a bare list of videos someone watched. Before any of it can be analysed, the Hub has to scrape each video (download it and its details) and then annotate it (record what it shows and is about). Both steps cost money. Armed, this collection gets that done by itself, a batch at a time. It always takes the cheapest step first: videos that are already scraped but not yet annotated are annotated before any new scraping starts. Then it cycles - pick the next videos, scrape them, check what actually arrived, annotate those, repeat. It never tries to annotate a video that was not scraped. It moves on its own about once an hour, and again whenever a scrape or annotation finishes. Any number of collections can be armed at once - they take turns, one batch per turn, through the same shared scraper and annotator, so plans never collide. Work done outside a plan is seen too: a video that is already scraped or annotated is skipped, never paid for twice. A plan stops when its annotation target is met, or when nothing processable is left. For it to run unattended, automatic enrichment must also be switched on for the whole site (Admin -> Site Settings); with that off, only Run a cycle now does anything.") }}

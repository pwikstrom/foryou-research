Getting started

Everything here revolves around a study — a set of participant data (which collections, which platforms, which dates) that a researcher defines and shares. Pick your active study from the dropdown in the header before you open an analysis tab; every tab works against whatever is selected there.

{% if user.can_access('tab.explore') %}

Explore

Browse and filter what participants watched, and compare two slices of the data side by side.

{% endif %} {% if user.can_access('tab.timelines') %}

Timelines

Follow one participant's feed day by day and spot rising, falling or spiking categories.

{% endif %} {% if user.can_access('tab.video_analysis') %}

Video Analysis

Watch individual videos, inspect their AI labels, and add your own tags and notes.

{% endif %} {% if user.can_access('tab.correlations') %}

Correlations

Chart relationships between numeric measures across groups of participants.

{% endif %} {% if user.can_access('tab.sessions') %}

Sessions

Open a single viewing session minute by minute, with binges and low-entropy stretches marked.

{% endif %} {% if user.can_access('tab.semantic_space') %}

Semantic Space

A map of every annotated video by meaning — explore the corpus's micro-genres.

{% endif %}

Nothing in the study picker? That's normal for a brand-new account: studies are shared with you by the researcher who defined them, so ask the person who invited you to share one. Nothing is broken.

{% if user.can_access('tab.data_management.ingestion') %}

Have participant data to add? Upload export files under Data Pipeline → Ingest Collections; once ingested, they can be included in a study.

{% endif %}

The ? button in the top right always explains the tab you're on, and the full guide describes the whole pipeline, including the parts your account doesn't reach.
